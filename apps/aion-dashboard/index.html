Flow Builder

            
Guided flow drafting, validation, dry-run planning, and stored flow inspection using existing /flows and /dashboard/flows APIs only.

          

          

            
            
          

        


        

          Constrained visual draft editing only. This milestone does not add arbitrary drag-and-drop, arbitrary edge editing, stored-flow graph mutation, execution, broker subscriptions, MQTT publish, HTTP forward, observation writes, event creation, command creation, or DLQ writes.
        


        

          Token mode guidance: flows:read for flow reads, validation, and dry-run; flows:write for create, enable, disable, and delete; dashboard:read for /dashboard/flows*; connectors:read for connector selectors.
